# MRD — 한국형 Commitment App
> 버전: v1.0 (Phase 3 개정)  
> 대상 시장: 대한민국  
> 제품 단계: MVP 확장 (Phase 3)  
> 문서 목적: 시장 문제, 타깃 고객, 포지셔닝, 경쟁 환경, 사업 가설을 정의한다.

---

## 1. 제품 개요

### 한 줄 정의
할 일을 기록하는 앱이 아니라, **사용자가 스스로 빠져나가기 어렵게 만드는 나와의 약속 앱**.

### 강제력 모드 (Enforcement Modes)
사용자는 약속마다 “얼마나 세게 지키고 싶은지”를 스스로 고른다. 셋 중 하나:
- **SELF** — 나만 확인. 증명은 남기되 돈은 걸지 않는다.
- **SOCIAL** — 친구에게 결과가 알려진다. 사회적 압박이 있지만 금전 이동은 없다.
- **MONEY** — 실제 약속금을 걸어 실패 시 돌려받지 못한다.

돈은 여전히 JIKYEO의 강력한 차별화 기능이지만, **모든 약속에 돈이 필수는 아니다**. 사용자는 목표의 성격과 자신의 각오에 맞춰 강제력을 조절한다.

### 핵심 루프
**약속 만들기 → 강제력 선택 → 규칙/증명 방식 정하기 → 행동하기 → 증명하기 → PASS / UNCERTAIN / FAIL 판정 → (MONEY일 때) 환급 · 미환급 → 다음 약속**

### 핵심 가치
- 의지가 약해서가 아니라, **행동을 강제하는 구조가 없어서 목표를 놓치는 문제**를 해결한다.
- 사용자는 목표를 단순히 “기록”하지 않고 **측정 가능한 계약**으로 만든다.
- 강제력은 사용자가 고른다. SELF/SOCIAL/MONEY 중 어느 방식이든 판정(PASS/UNCERTAIN/FAIL)은 동일한 원칙으로 이뤄진다.
- MONEY 모드일 때만 금전이 움직인다. 성공하면 지키고 실패하면 돌려받지 못한다.
- Financial Accountability와 Social Accountability는 항상 분리된 시스템이다. **친구는 실패금을 절대 받지 않는다.**

## 2. 시장 문제

### 주요 사용자 문제
1. 목표를 세워도 며칠 안에 흐지부지된다.
2. 일반 습관앱은 체크박스와 스트릭만 제공해 강제력이 약하다.
3. 스스로 성공 여부를 누르면 되기 때문에 자기합리화가 쉽다.
4. 목표가 추상적이라 실제 행동으로 이어지지 않는다.
5. 실패했을 때 즉시 체감되는 비용이 없다.
6. 혼자만 아는 목표는 쉽게 포기한다.

### 기존 대안의 한계
- **Habit Tracker**: 기록은 잘하지만 강제력이 약함.
- **앱 차단 서비스**: 디지털 중독 문제에는 강하지만 범용 현실 행동을 다루기 어려움.
- **챌린지형 서비스**: 정해진 챌린지에 참가하는 방식이 많고, 개인이 자유롭게 계약을 설계하기 어려움.
- **커뮤니티형 서비스**: 사회적 압박은 있지만 실제 금전적 손실이 없음.
- **해외 Forfeit**: 기능은 검증됐지만 한국어/한국 결제/한국 사용자 정서에 최적화되어 있지 않음.

## 3. 타깃 고객

### Primary Persona A — 계획은 세우지만 잘 미루는 20~39세
- 공부, 자격증, 운동, 기상, 스마트폰 사용시간 관리 니즈
- 생산성 앱 사용 경험 있음
- “이번엔 진짜 해야 하는데”라는 상황이 반복됨
- 3,000~20,000원 수준의 작은 손실은 강한 동기부여가 됨

### Primary Persona B — 목표가 명확한 시험/취준 사용자
- 자격증, 공채, 면접, 포트폴리오, 코딩테스트 준비
- 마감기한이 명확함
- 공부 시간, 문제 풀이, 도서관 출석 등 검증 가능한 행동이 많음

### Primary Persona C — 생활 습관을 바꾸려는 직장인
- 기상, 운동, 독서, 명상, 배달음식, SNS 제한
- 반복 목표를 주간 계약으로 만들기 좋음
- 친구에게 실패가 공개되는 구조에 반응 가능성이 높음

### Secondary Persona
- 프리랜서/창작자: 작업 마감, 업로드, 영업 연락
- 학생: 과제, 공부시간, 출석
- 운동 사용자: 헬스장 방문, 걸음수, 운동시간

## 5. 포지셔닝

### 카테고리
**Commitment Contract / Accountability App**

### 우리가 아닌 것
- 할 일 관리 앱
- 단순 습관 체크 앱
- SNS
- 도박/베팅 서비스
- 상금 경쟁형 챌린지
- 친구끼리 실패금을 나눠 갖는 서비스

### 핵심 포지셔닝 문장
> **“의지를 믿지 말고, 빠져나가기 어렵게 만들어봐요.”**

강도는 사용자가 고른다. 나만 확인해도 되고, 친구에게 알려도 되고, 돈까지 걸어도 된다.

### 제품 언어
- “베팅”, “도박”, “상금” 대신 **약속 / 약속금 / 증명 / 지킨 돈 / 놓친 약속**을 사용
- 실패금을 다른 사용자에게 분배하지 않음
- 금전 계약은 항상 사용자 자신의 약속에 귀속

## 7. 사업 모델

### MVP 수익/결제 가정
- 결제 흐름은 **MONEY 모드로 생성된 약속에만** 적용된다.
- 챌린지 생성 시 **약속금 선결제** (MONEY 전용)
- 성공한 회차의 약속금은 환불/결제취소
- 실패한 회차의 약속금은 환불하지 않음
- 실패금을 친구나 다른 성공자에게 분배하지 않음
- 사용자 간 자금 이동 기능 없음
- SELF/SOCIAL 모드는 어떠한 금전 흐름도 발생시키지 않는다. Stake row 자체가 생성되지 않는다 (0원 Stake로 표현하지 않음).
- 세부 귀속 방식은 법무/PG 검토를 전제로 확정
- MONEY 모드에는 서버가 강제하는 티어별 상한이 존재한다 (StakePolicy 참조).

### 구독 모델
장기적으로 실패금만으로 수익화하지 않는다.

예시:
- Free: 동시 활성 약속 1개, 기본 검증
- Premium: 활성 약속 4개, 모든 기본 검증, 리포트
- Pro: 무제한 약속, AI 약속 설계, 고급 통계, 고급 검증

> 실패가 플랫폼의 유일한 수익원이 되면 “사용자가 실패해야 플랫폼이 돈 번다”는 이해상충이 커지므로, 장기적으로는 구독이 주 수익원이어야 한다.

## 10. 시장 가설

### H1
실제 돈이 걸리면 동일한 목표에서도 성공률이 높아진다.

### H2
친구에게 결과가 공개되면 금전 약속 없이도 성공률이 높아진다.

### H3
금전 + 친구 공개를 동시에 사용하면 가장 높은 성공률을 보인다.

### H4
자유 입력보다 템플릿 기반 계약 생성이 첫 계약 생성률을 높인다.

### H5
사용자에게 “돈을 잃었다”보다 “돈을 지켰다”를 강조하면 장기 유지율이 높아진다.

### H6
SELF 모드만으로도 습관앱 대비 성공률이 높다. 사용자가 강제력의 수위를 선택할 수 있다는 사실 자체가 첫 계약 생성률을 높인다.

### H7
사용자는 처음에는 SELF/SOCIAL로 시작하고, 반복 성공 이후 MONEY로 자연스럽게 이동한다. 강제력 상승은 판매 전략이 아니라 사용자의 결정으로 이루어진다.

## 11. 출시 전 필수 확인

- 선정 PG는 NHN KCP. 카카오페이/카드는 KCP 뒤 결제 수단이다. KCP가 “선결제 → PASS/VOID 환불 → 확정 FAIL만 대가”를 서면 허용하는지.
- 약속금 귀속 및 약관 문구의 약관법/전자상거래법 검토
- 실패금 상한 및 월 최대손실 기준
- 미성년자 사용 제한
- 위험 목표 및 건강 관련 목표 차단 정책
- 앱스토어 심사 시 도박/베팅 서비스로 오해되지 않도록 설명 체계 정리

## 12. UI/UX 방향

### Toss에서 참고할 원칙
브랜드를 복제하지 않고 아래 원칙만 따른다.
- 한 화면에 한 가지 판단/행동
- 어려운 단어 대신 일상적인 한국어
- 숫자는 크게, 설명은 짧게
- 사용자가 잃을 수 있는 금액을 숨기지 않음
- 버튼 카피는 행동형으로 명확하게
- 에러보다 다음 행동을 먼저 제안
- 긴 약관은 숨기되, 돈/실패 조건은 절대 숨기지 않음
- 상태 변화는 즉시 보여줌

### 예시 카피
- “이번엔 진짜 지키고 싶은 약속이 있나요?”
- “어떻게 지키게 만들까요?”
- “못 지키면 얼마를 걸까요?” (MONEY 모드에서만)
- “이렇게 증명할게요”
- “지금부터 약속이 시작돼요”
- “약속을 지켰어요” / “₩10,000을 지켰어요” (모드별로 문구 분기)
- “약속을 놓쳤어요”
- “판정이 이상한가요? 다시 확인해드릴게요”

### 카피 원칙 — 돈이 걸리지 않은 약속에서 돈 이야기를 하지 않기
SELF/SOCIAL 약속에는 “0원 걸림”, “최대 손실 없음”, “환불” 같은 금전 문구를 절대 노출하지 않는다. 돈 UI는 관계 없을 때 완전히 사라진다.
